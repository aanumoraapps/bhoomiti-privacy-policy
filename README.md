# BhooMiti Privacy Policy

This public repository hosts the privacy policy webpage for the Android app **BhooMiti** (`com.mora.bhoomiti`).

It intentionally contains only static privacy-policy website files. It must not contain Android app source code, API keys, signing files, build outputs, secrets or proprietary project files.

## GitHub Pages

Configure GitHub Pages to deploy from:

- Branch: `main`
- Folder: `/ (root)`

Expected URL after publication:

`https://manishranjanprogrammer-del.github.io/bhoomiti-privacy-policy/`

## Required placeholders

Before final store submission, replace the Contact section placeholders in `index.html` with the official developer/publisher name and privacy contact email.
